# Motion POS

نظام كاشير وإدارة للكافيهات والمطاعم: الكاشير، والطاولات، والمطبخ، والمخازن، والمشتريات، والخزينة، والحسابات، والتقارير.

## روابط

| | العنوان |
|---|---|
| الموقع الحقيقي (فرع `main`) | https://motion-pos.vercel.app |
| موقع التجربة (فرع `dev`) | https://motion-pos-git-dev-johnsamire-2468s-projects.vercel.app |
| خطة التنفيذ الكاملة | [docs/MotionPOS_Plan.md](docs/MotionPOS_Plan.md) |

## طريقة البناء

- الواجهة: HTML و Tailwind و JavaScript.
- قاعدة البيانات: Supabase (PostgreSQL 17).
- النشر: Vercel، بيتحدّث لوحده مع كل رفع على جيت هاب.

## قواعد الشغل

1. الشغل كله على فرع `dev`، ويتجرّب على موقع التجربة، وبعد التأكد يتنقل لـ `main`.
2. أي تعديل على قاعدة البيانات يبقى ملف مترقّم في `supabase/migrations/`.
3. ممنوع أي سر (كلمة سر أو مفتاح سري) يدخل المشروع. المسموح المفتاح العام بس.
4. النسخ الاحتياطية للبيانات بتتحفظ برّه المشروع، ومتترفعش أبداً.

**قبل أي شغل: اقرا [docs/MotionPOS_Plan.md](docs/MotionPOS_Plan.md).**
